# Aplikasi Kuliner Khas Juhu Singkah (Rotan Muda) - CodeIgniter 4 & Tailwind CSS

Aplikasi web kuliner khas Dayak Kalimantan Tengah **Juhu Singkah** yang dikembangkan menggunakan **CodeIgniter 4** dan **Tailwind CSS**.

## 🌟 Fitur Utama
1. **Halaman Utam (Homepage)**:
   - Menampilkan 8 variasi hidangan khas Juhu Singkah (Umbut Rotan).
   - Pencarian interaktif & filter kategori makanan.
   - Banner edukasi kuliner tradisional Kalimantan.
2. **Halaman Detail Makanan (`/detail/{id}`)**:
   - Tampilan visual gambar high-res berlabel AI Studio.
   - Rincian resep, bahan rempah utama, dan info nutrisi.
   - **Kalkulator Porsi Interaktif**: Hitung estimasi harga secara real-time.
   - Seksi ulasan & rating pelanggan.
   - Pemesanan langsung via WhatsApp.
3. **Panel Admin & CRUD (`/admin`)**:
   - Login admin terproteksi session (`/login`).
   - Fitur **Create, Read, Update, Delete** untuk mengelola menu Juhu Singkah.
4. **Desain & Tema**:
   - Palette warna utama: `#6366F1` (Indigo) & Warna Aksen: `#FDE68A` (Amber/Soft Gold).
   - Menggunakan Tailwind CSS CDN.
